# Tsukyryll - Landing Page


**Compra de Moedas Virtuais para Jogos Online**

Uma landing page moderna e atrativa desenvolvida como projeto escolar para demonstrar habilidades em desenvolvimento front-end.

---

## 📋 Sobre o Projeto

**Tsukyryll** é uma landing page fictícia de uma plataforma especializada na venda de moedas virtuais (in-game currency) para diversos jogos online populares.

O objetivo do projeto é apresentar uma interface profissional, responsiva e visualmente impactante, simulando uma experiência real de e-commerce de produtos digitais.

### 🎯 Objetivo
Desenvolver uma landing page completa utilizando apenas tecnologias front-end (HTML, CSS e JavaScript), aplicando boas práticas de design, animações e responsividade.

---

## ✨ Funcionalidades

- **Design moderno e imersivo** com tema gamer/dark
- **Seção Hero** com call-to-action impactante
- **Catálogo de jogos** com cards interativos
- **Vantagens da plataforma** (segurança, rapidez, suporte, etc.)
- **Depoimentos** de clientes fictícios
- **FAQ** interativo (acordeão)
- **Formulário de contato** funcional (simulado)
- **Menu de navegação** com rolagem suave
- **Responsivo** para dispositivos móveis, tablets e desktop
- **Animações** com CSS e JavaScript
- **Efeitos hover** e partículas interativas

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização avançada, Flexbox, Grid, animações
- **JavaScript (Vanilla)** - Interatividade, menu mobile, FAQ, scroll suave
- **Google Fonts** - Tipografia personalizada
- **Imagens** otimizadas e ícones
